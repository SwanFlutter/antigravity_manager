# راهنمای نصب و استفاده از Antigravity Manager

نرم‌افزار **Antigravity Manager** یک اپلیکیشن دسکتاپ برای ویندوز است که اکانت‌های سرویس‌های کدنویسی هوش مصنوعی (مانند Google Cloud Code / Gemini) را مدیریت می‌کند، سهمیه‌ها را نشان می‌دهد و یک پروکسی/گیت‌وی محلی را اجرا می‌کند تا ابزارهای کدنویسی شما بتوانند از طریق یک کلید API از آن‌ها استفاده کنند.

---

### 🏛️ معماری و اجزای برنامه

این برنامه از دو بخش مجزا تشکیل شده که با هم کار می‌کنند:
1. **فرانت‌اند (رابط کاربری فلاتر):** فایل `antigravity_manager.exe` که پنل گرافیکی، مدیریت اکانت‌ها، آزمایشگاه (Playground) و لاگ ترافیک را فراهم می‌کند.
2. **بک‌اند (هسته Rust و پروکسی):** فایل `antigravity-host.exe` که مدیریت پایگاه داده SQLite، نشست‌های OAuth گوگل، بررسی سهمیه‌ها و گیت‌وی محلی API را بر عهده دارد.

وقتی فایل `antigravity_manager.exe` را اجرا می‌کنید، برنامه به طور خودکار فایل `antigravity-host.exe` را (اگر در حال اجرا نباشد) در پس‌زمینه استارت کرده و از طریق Named Pipe با آن ارتباط برقرار می‌کند.

---

### 📥 نصب و راه‌اندازی برای کاربران

#### ۱. دانلود و استخراج (Release)
1. به صفحه [GitHub Releases](https://github.com/SwanFlutter/antigravity_manager/releases) پروژه مراجعه کنید.
2. آخرین نسخه فایل فشرده `antigravity-manager-windows-x64.zip` را دانلود کنید.
3. فایل زیپ را در یک پوشه دلخواه روی ویندوز خود (مثلاً در درایو C یا دسکتاپ) استخراج (Extract) کنید.

> **⚠️ نکته بسیار مهم درباره شبکه و لوکیشن:**
> گوگل روی سرویس‌های Cloud Code / Gemini حساسیت لوکیشنی دارد. برای جلوگیری از خطاهای مسدودی (`TOS_VIOLATION`) یا نیاز به وریفای مکرر (`VALIDATION_REQUIRED`)، حتماً هنگام لاگین و استفاده از برنامه از **VPN یا پروکسی مناسب، پایدار و تمیز** استفاده کنید.

#### ۲. اجرای برنامه
1. روی فایل **`antigravity_manager.exe`** دابل‌کلیک کنید.
2. به تب **Accounts** بروید و اکانت گوگل خود را از طریق دکمه اتصال متصل کنید.
3. به تب **API Proxy** بروید و گیت‌وی محلی را روی پورت پیش‌فرض (`8045`) روشن کنید.
4. ابزارهای هوش مصنوعی خود (مانند Cline، Continue و...) را به آدرس `http://127.0.0.1:8045/v1` به همراه کلید API محلی متصل کنید.

---

### 🛠️ رفع مشکلات و خطاهای رایج

* **نیاز به تأیید هویت (`VALIDATION_REQUIRED`):** اگر گوگل از شما وریفای خواست، روی دکمه **«تأیید هویت اکانت»** در کارت اکانت کلیک کنید تا صفحه رسمی گوگل در مرورگر باز شود.
* **مسدودی حساب (`TOS_VIOLATION`):** اگر اکانت توسط گوگل محدود شد، می‌توانید با زدن دکمه **«ثبت اعتراض»** درخواست بررسی ارسال کنید یا یک اکانت گوگل جدید متصل نمایید.
* **پروکسی محلی:** تغییر کلید API محلی محدودیت‌های سرور گوگل را برطرف نمی‌کند؛ بلکه باید مطمئن شوید IP شبکه و پروکسی شما معتبر و پایدار است.
